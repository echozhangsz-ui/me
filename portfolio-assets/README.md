# 星座履历首页 · 程序美术素材

基于本次选中的星座首页设计图重绘拆分，共 8 张独立 RGBA PNG。它们不是原始 PSD 的无损切片，局部纹理与形状会有差异。此包对应星座首页，不是半透明地球仪页面。

所有 PNG 均有真实 Alpha 通道；透明区不是黑色或棋盘格。发光边缘保留渐变透明度，适合在深蓝背景上使用。PNG 使用普通 straight alpha，浏览器直接用 img 加载即可。

图像有透明留边，显示尺寸包含留边。保留宽高比，切勿把图像拉伸成不同长宽比例。九个经历节点复用星点，第十个位置复用圆环。

## 建议图层顺序

1. CSS 深蓝底色：#06152A。
2. starfield：覆盖页面，按需调整透明度；不要用 repeat。
3. landscape：底部居中，在页脚上方；保持完整宽高比，避免裁掉左右地标。
4. SVG / Canvas 星座连线。
5. 蓝色 / 金色星点与公司名称、日期、职位。
6. 项目预览面板与内容。
7. 临时飞行星光（pointer-events: none）。

## 应由程序绘制的内容

- 姓名与全部正文、年份、问号、按钮文案：HTML 文字，保证清晰、可选取与可访问。
- 星座连线：SVG path，跟随节点坐标；避免把连线烘焙进背景图。
- 按钮底、边框、圆角、预览面板：CSS。这样能适配不同文案长度和屏幕尺寸。
- 下载箭头、导航箭头和辅助图标：采用项目现有的矢量图标库。
- 公司 Logo：使用各公司的正式品牌源文件；本包未将概念稿里生成的字标作为正式 Logo 交付。
- 项目缩略图：替换为真实项目截图；概念稿中的体素场景只是示意。

## 动画接入

点击经历后可用蓝色/金色 PNG 交叉淡入切换；一份粒子素材沿节点到目标字母的曲线路径移动。粒子图的亮点在画布约 (0.77, 0.45)，定位时应以该点为运动锚点。这些都是静态纹理，动画逻辑需要前端实现。

可从 example.css 中的基础样式开始。根据布局调整位置，不要把素材原始像素尺寸当成页面显示尺寸。

## 检查结果

8 张文件均可完整解码，格式 RGBA，Alpha 最小值 0、最大值 255，均包含部分透明像素；已在 #06152A 背景上检查叠加效果。素材经 image_gen 基于所选参考重绘，之后做透明通道准备。资产清单见 manifest.json。
